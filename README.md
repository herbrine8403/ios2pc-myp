A PC plugin that enables iOS devices to connect to MicYou as wireless microphones.

</div>

## Features

- **Protocol Conversion**: Converts iOS protocol to Android protocol for MicYou compatibility.
- **Virtual Android Client**: Emulates an Android client on PC to receive iOS audio streams.
- **Audio Forwarding**: Forwards audio from iOS devices to the MicYou desktop server.

## Usage

1. Install the plugin in the MicYou PC application.
2. Enable the plugin in the settings.
3. Connect your iOS device and start streaming.

## Note

- **ios2pc** is a shorthand for **iOS To PC**.
- This repository is a standalone project and is **not included** in the main MicYou repository.
- If you encounter any issues, please submit them to the [ios2pc Issues](https://github.com/herbrine8403/ios2pc-myp-v2/issues) or [MicYou-iOS Issues](https://github.com/MicYou-Dev/MicYou-iOS/issues).
